# Eesti–inglise sõnastik

| Eesti mõiste | Inglise vaste | Tähendus |
|---|---|---|
| Aktiivtootlus | Active return | Portfelli ja valitud baasi tootluste vahe. |
| Alpha | Alpha | Riskimudeli seletamata tootluse komponent; sõltub mudelist. |
| Beeta | Beta | Tundlikkus turu või muu faktori muutusele. |
| Faktor | Factor | Ühine tootluse seletaja või vara omadus. |
| Momentum | Momentum | Varasema suhtelise hinnaliikumise jätkumise hüpotees või tunnus. |
| Universum | Universe | Enne katset määratud lubatud varade kogum. |
| Võrdlusportfell | Benchmark | Otsuse ja tulemuse võrdlusalus. |
| Kogutootlus | Total return | Hinnamuutuse ning väljamaksete järjekindlalt arvestatud tootlus. |
| Volatiilsus | Volatility | Tootluste hajuvus valitud sagedusel. |
| Kovariatsioon | Covariance | Kahe suuruse ühine muutumine. |
| Korrelatsioon | Correlation | Standardiseeritud lineaarse seose mõõt. |
| Langus tipust | Drawdown | Väärtuse vähenemine senisest tipust. |
| Käive | Turnover | Kaubeldud maht kapitali suhtes; definitsioon täpsustada. |
| Libisemine | Slippage | Täitmishinna erinevus valitud võrdlushinnast. |
| Turumõju | Market impact | Oma orderi mõju turuhinnale. |
| Likviidsus | Liquidity | Võimalus kaubelda soovitud mahus piiratud hinnamõjuga. |
| Järeltest | Backtest | Ajalooline strateegiasimulatsioon. |
| Tulevikuinfo leke | Look-ahead bias | Otsustamine tol hetkel teadmata andmetega. |
| Ellujäämiskallutatus | Survivorship bias | Allesjäänute valikust tingitud moonutus. |
| Üleõppimine | Overfitting | Valimimüra sobitamine üldistuva seose asemel. |
| Punkt-ajas | Point-in-time | Info kasutamine ajaloolise kättesaadavuse järgi. |
| Tunnus | Feature | Mudeli sisendiks teisendatud mõõtmine. |
| Sihtmuutuja / silt | Target / label | Õpitav tulemus ja selle realiseerumise aeg. |
| Regulaarimine | Regularization | Keerukuse või parameetrite piiramine üldistumise parandamiseks. |
| Juhumets | Random Forest | Juhuslikustatud otsustuspuude ansambel. |
| Gradientvõimendus | Gradient boosting | Järjestikused senist mudelit parandavad õppurid. |
| Ajas edasi testimine | Walk-forward | Minevikul treenimine ja järgneval ajaplokil hindamine. |
| Valimiväline | Out-of-sample | Vaatlus, mida vastava mudeli sobitamisel ei kasutatud. |
| Simuleeritud reaalajakauplemine | Paper trading | Reaalajas virtuaalsete orderitega süsteemikontroll. |
| Otsinguga täiendatud genereerimine | RAG | Otsitud tõendite andmine teksti genereerivale mudelile. |
| Agent | Agent | Süsteem, mis valib eesmärgi suunas tööriistakasutuse samme. |
| Päritolu | Provenance | Allika ja teisenduste jälgitav ajalugu. |
| Triiv | Drift | Kaalu, andmejaotuse või seose muutus; kontekst tuleb täpsustada. |
| Võimendus | Leverage | Kapitali suhtes suurendatud ekspositsioon. |
| Kapasiteet | Capacity | Maht, mille juures strateegiat saab majanduslikult teostada. |
| Osaku puhasväärtus | NAV per share | Fondi netovara väärtus ühe osaku kohta. |
| Baasipunkt | Basis point | 0,01 protsendipunkti; 10 bp = 0,1%. |
| Kuluvaba tootlus | Gross return | Tootlus enne kirjeldatud kulude mahaarvamist. |
| Netotootlus | Net return | Tootlus pärast kirjeldatud kulusid; alati täpsusta milliseid. |
| Mudeliseire | Model monitoring | Sisendi, prognoosi ja realiseerunud toimivuse jälgimine. |
