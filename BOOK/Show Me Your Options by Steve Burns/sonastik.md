# Eesti–inglise mõistete sõnastik

[Tagasi](README.md)

| Eesti | English | Tähendus |
|---|---|---|
| Optsioon | Option | Lepinguline õigus kindlatel tingimustel osta või müüa. |
| Alusvara | Underlying | Vara või indeks, millest lepingu väärtus sõltub. |
| Ostuoptsioon | Call | Õigus osta või saada vastav rahaline arveldus. |
| Müügioptsioon | Put | Õigus müüa või saada vastav rahaline arveldus. |
| Täitmishind | Strike price | Lepingus määratud tehinguhind. |
| Preemia | Premium | Optsiooni ostuhind / müüjale makstav hind. |
| Lõpptähtaeg | Expiration | Lepingu õiguse lõppemise tähtaeg. |
| Kordaja | Multiplier | Noteeringu rahaliseks summaks teisendav tegur. |
| Üleantav vara | Deliverable | Täitmisel üle antav lepinguline vara; kontrolli korrigeeritud lepinguid. |
| Täitmine | Exercise | Ostja lepingulise õiguse kasutamine. |
| Kohustuse määramine | Assignment | Müüjale täitmiskohustuse määramine. |
| Pikk positsioon | Long | Ostetud õigus või omatud vara. |
| Lühike positsioon | Short | Müüdud optsioonikohustus või lühikeseks müüdud vara. |
| Avav ost | Buy to open | Uue pika optsioonipositsiooni loomine. |
| Sulgev müük | Sell to close | Pika optsioonipositsiooni lõpetamine. |
| Avav müük | Sell to open | Uue lühikese optsioonipositsiooni loomine. |
| Sulgev ost | Buy to close | Lühikese kohustuse tagasiost. |
| Rahas | In the money / ITM | Positiivne sisemine väärtus; mitte tingimata kasum. |
| Raha juures | At the money / ATM | Alusvara hind strike’i lähedal. |
| Rahast väljas | Out of the money / OTM | Sisemine väärtus null, õigus pole hetkel soodne. |
| Sisemine väärtus | Intrinsic value | Call’il max(S−K,0), put’il max(K−S,0). |
| Väline väärtus | Extrinsic value / time value | Turuhinna ja sisemise väärtuse vahe. |
| Väljamakse | Payoff | Lepingujalgade tulemus tähtajal enne algse hinna arvestamist. |
| Kasum/kahjum | Profit/loss / P/L | Tulemus pärast algset rahavoogu; täpsusta kulude arvestus. |
| Tasuvuspiir | Break-even | Hind, mille juures määratletud ajamomendi P/L on null. |
| Eeldatav volatiilsus | Implied volatility / IV | Optsiooni hinnast mudeliga tuletatud volatiilsus. |
| Realiseerunud volatiilsus | Realized volatility | Valitud perioodil tegelikult mõõdetud kõikumine. |
| Volatiilsuskalle | Volatility skew | IV erinevus strike’ide vahel. |
| Tähtajastruktuur | Term structure | IV või muu suuruse erinevus tähtaegade vahel. |
| Ostupakkumine | Bid | Hind, millega noteerija on valmis ostma. |
| Müügipakkumine | Ask | Hind, millega noteerija on valmis müüma. |
| Hinnavahe | Bid-ask spread | Ask’i ja bid’i erinevus. |
| Likviidsus | Liquidity | Võime kaubelda soovitud kogust mõistliku hinnamõjuga. |
| Avatud lepingute arv | Open interest | Avatud lepingute kogus; pole sama mis päevamaht. |
| Tagatisnõue | Margin requirement | Maakleri või kliiringu nõutav riskipuhver. |
| Täitmisnihe | Slippage | Tegeliku täitmishinna erinevus eeldatud hinnast. |
| Delta | Delta | Hinna osatundlikkus alusvara hinna suhtes. |
| Gamma | Gamma | Delta osatundlikkus alusvara hinna suhtes. |
| Theta | Theta | Hinna muutuse tundlikkus aja möödumise suhtes. |
| Vega | Vega | Hinna tundlikkus IV suhtes. |
| Rho | Rho | Hinna tundlikkus intressi suhtes. |
| Deebet | Debit | Avamisel netos makstav summa. |
| Krediit | Credit | Avamisel netos laekuv summa. |
| Jalg | Leg | Üks komponent mitmeosalisest strateegiast. |
| Oodatav väärtus | Expected value | Tulemuste tõenäosustega kaalutud keskmine. |
| Sabarisk | Tail risk | Harvade, sageli väga suurte tulemuste risk. |
| Baasirisk | Basis risk | Kaitstava vara ja maandusinstrumendi erineva liikumise risk. |
| Langus tipust | Drawdown | Kapitali vähenemine varasemast tipust. |
| Rollimine | Rolling | Vana positsiooni sulgemine ja uue avamine. |
| Riskineutraalne mõõt | Risk-neutral measure | Hinnastamise tõenäosusraamistik, mitte automaatselt tegelik prognoos. |
| Pariteet | Put-call parity | Sama strike’i ja tähtajaga Euroopa call’i/put’i rahavoogude hinnaseos. |
| Samal päeval aeguv | 0DTE | Optsioon, mille tähtaeg on tänane päev. |
| Strike’i ümbruse aegumisrisk | Pin risk | Ebakindlus tähtajal kujuneva positsiooni suhtes strike’i lähedal. |
