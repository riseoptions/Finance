# Investeerimine, Python ja AI

Eestikeelne **13 mooduliga kompaktne põhikursus** Stefan Pappi „Investing for Programmers” teemadel. Valmis on õppetekst, õpetajamaterjal, lahendustega töölehed, kood, Colabi märkmikud ja offline-lõpuprojekt. Edasijõudnud jätkumoodulid ja testimata võrguliidesed on ausalt eristatud.

## Alusta siit

1. [Õppeprogramm ja raamatu kaart](OPPEKAVA.md)
2. [Põhiõpik](OPIK.md)
3. [Keskkonna seadistamine](SEADISTUS.md)
4. Ava Thonnys `kood/m01.py`, käivita F5.
5. Lõpuks käivita `kood/koik_etapid.py` ja ava `valjund/koondraport.md`.
