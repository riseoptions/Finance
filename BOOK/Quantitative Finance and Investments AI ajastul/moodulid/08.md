# 08. LLM, RAG, teadmistegraaf ja AI-agent

[Tagasi sisukorda](../README.md) · Raamatu peatükid: 10, 22, 23, 24. Täpsed PDF-lehed: [raamatukaart](../RAAMATU_KAART.md). Allikate S-koodid: [allikad](../ALLIKAD.md).

## Intuitsioon ja sisu

LLM on keele ja mustrite mudel, RAG lisab talle otsitavad allikad, agent lisab võimaluse valida järgmisi tööriistakasutusi. Raamatukogu analoogias on LLM kirjutaja, otsing kataloog ja agent töökorraldaja. Kataloogis oleva raamatu leidmine ei taga õiget tõlgendust.

[RAAMAT] Ptk 22–24 eristavad tõenditega dokumendianalüüsi, suhete otsingut ja agentseid töövooge. [SELGITUS] RAG-i sammud: dokumentide vastuvõtt → tükeldamine koos päritoluga → otsing → asjakohasuse kontroll → vastus koos viidetega → väidete kontroll. Otsida saab TF-IDF-i, BM25 või embedding’utega; väikese korpuse jaoks pole vektorandmebaas kohustuslik.

Ajafilter peab rakenduma enne otsingut. Lisaks võib mudeli eeltreening sisaldada hilisemaid fakte: ajalooline LLM-test vajab teadmiste saastumise käsitlust isegi siis, kui RAG-korpus on ajaliselt korrektne. Praegune mudel ja 2018. aasta aruanne ei võrdu automaatselt 2018. aasta analüütikuga.

Teadmistegraaf seob näiteks ettevõtte, tarnija ja piirkonna. Serval peab olema allikas ja kehtivusaeg. Agent on põhjendatud siis, kui järgmine samm sõltub leitust: vaja on teist lõiku, puuduva mõõdiku kontrolli või vastamisest loobumist. Fikseeritud igapäevane raport sobib sageli tavalise skriptiga.

## Mis muutus ja miks?

Generatiivne AI muudab teksti struktureerimise paindlikumaks. See lisab hallutsinatsioonide, prompt injection’i ja ebastabiilsete vastuste riski. Uuringud näitavad LLM-ide potentsiaali finantsaruannete analüüsis kindlates katsetes [S9], mitte garanteeritud börsiedu.

## Lihtne näide

[NÄIDE] Aruandes on Revenue 120 ja varasem väärtus 100. LLM tuvastab väljad ja allikad; Python arvutab kasvu 20%. Kui aruandest puudub kasum, peab süsteem vastama „andmed puuduvad”, mitte pakkuma usutavat arvu.

kasv=(120−100)/100=20%. Viitetäpsus = kontrollitud väidet toetavad viited / kontrollitud viited. Täielikkus = leitud nõutud faktid / kõik nõutud faktid. Kõrge viitetäpsus ei taga täielikkust.

## Praktiline rakendus

07_rag_agent.py töötab esmalt lokaalse otsingu demonstratsioonina. --live-llm loob API kaudu tekstianalüüsi; --agent lubab kuni kolm piiratud tööriistavaliku sammu. Offline-režiim ei ole LLM ega AI-agent. Võrdle käsitsi koostatud vastusevõtmega, mitte mudeli enesehinnanguga.
